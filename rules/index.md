# Memory bank — Task Manager

Точка входа для агентов. **Не читай все `rules/` сразу.**

Протокол:

1. Этот файл — карта. Выбери папку по таблице.
2. Открой её `index.md` (содержимое + когда читать).
3. Читай только нужный файл. Планы — сначала секцию **«Статус реализации»**.
4. Код смотри по дереву в [basics/project_structure.py](basics/project_structure.py), не глобь весь репо без нужды.

В **каждой** папке `rules/` лежит `index.md`. После новой фичи обновляй статусы и этот индекс.

## Содержимое

| Путь | Что внутри | Когда читать |
|------|------------|--------------|
| [basics/](basics/index.md) | структура репо, слои, стек, эндпоинты | старт любой задачи |
| [code/](code/index.md) | стиль Python и тестов | пишешь/правишь код или тесты |
| [db/](db/index.md) | PostgreSQL: таблицы, драйвер, DDL | SQL, репозитории, схема |
| [development_plans/](development_plans/index.md) | планы фич + статус | работа по конкретной фиче / сверка «сделано ли» |

Cursor: `.cursor/commands/read-rules.md`, `.cursor/rules/` (venv, tests, memory-bank).
